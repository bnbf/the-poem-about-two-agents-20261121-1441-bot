A [make.fun](https://make.fun) entry: a program that writes one short poem about
agency — the power to choose and to act, and the agency that passes between two
agents when they agree on one plan — to `/output/entry.txt`.

`main.py` (Python 3.13, stdlib only, no network) writes the poem. The poem is
1–280 Unicode code points of UTF-8 text.
